# Unify Notifier

One notification bridge for AI coding agents in VS Code.

- Remote SSH / WSL / Dev Containers aware
- CodeBuddy hook configuration
- Claude Code hook configuration
- completion, approval, input-required, and failure notifications
- native desktop notifications through the local VS Code client

After installation run **Unify Notifier: Configure Agents**, then use **Unify Notifier: Test End-to-End Bridge** from a Remote SSH window to verify the full remote-to-local path.
